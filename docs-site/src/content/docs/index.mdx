## At a glance

| | |
|---|---|
| **Network** | Mezo (EVM-compatible Bitcoin Layer 2) |
| **Assets** | veBTC and veMEZO vote-escrowed NFTs (ERC-721) |
| **Payment tokens** | BTC, MEZO, MUSD — or any of them via automatic swap |
| **Custody** | Escrowless: the NFT stays in the seller's wallet until the moment of sale |
| **Settlement** | Atomic: NFT transfer and payment happen in one transaction, or not at all |
| **Protocol fee** | Currently 1%, hard-capped at 5%, changes timelocked 48 hours |
| **Analytics** | [Live dashboard on Dune](https://dune.com/vezo/vezo) |
