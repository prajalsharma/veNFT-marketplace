Vezo is an escrowless, peer-to-peer marketplace for **veBTC** and **veMEZO** vote-escrowed NFTs on [Mezo](/introduction/what-is-mezo/), Bitcoin's EVM Layer 2. These docs explain the asset class, the trading mechanics, the protocol architecture, and how to integrate against the contracts — use the sidebar to browse every page, or start with one of the paths below.
